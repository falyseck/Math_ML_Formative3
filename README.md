## 🧠 Project Overview

### Part 1: Probability Distributions
- Implemented the **bivariate normal distribution** from scratch in Python.  
- Computed the **probability density function (PDF)** for a chosen dataset.  
- Visualized the results using **Matplotlib** with both contour and 3D plots.

### Part 2: Bayesian Probability
- Used the **IMDb Movie Reviews dataset** to explore how keywords relate to sentiment.  
- Selected 3 positive and 3 negative keywords.  
- Computed:
  - Prior: `P(Positive)`
  - Likelihood: `P(keyword | Positive)`
  - Marginal: `P(keyword)`
  - Posterior: `P(Positive | keyword)`  
- Visualized and interpreted how specific keywords (like *excellent*, *boring*, etc.) correlate with sentiment.

### Part 3: Gradient Descent (Manual Calculation)
- Manually computed **two iterations** of gradient descent for a linear regression model.  
- Updated parameters `m` and `b` step by step to minimize **Mean Squared Error (MSE)**.  
- Each group member contributed one iteration.

### Part 4: Gradient Descent in Code
- Converted manual calculations into Python code using **SciPy** and **Matplotlib**.  
- Visualized how `m`, `b`, and the error evolve over multiple iterations.
